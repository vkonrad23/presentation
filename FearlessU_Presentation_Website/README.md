# FearlessU presentation website

A premium, responsive static presentation website for an accelerator application.

## Open it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. For deployment, upload the folder to Netlify, Vercel, GitHub Pages, or any static host.

## Before submitting
- Replace `founder@example.com` with the founder email.
- Add real founder name, location, company details, and verified links.
- Replace all roadmap language with actual, provable progress.
- Do not invent users, clinical outcomes, revenue, investment, or partnerships.
- Obtain clinical, legal, privacy, cybersecurity, and regulatory review before any health launch.
- Record the 60-second pitch from the script in the website modal.
- Confirm accelerator eligibility, participation fee, dates, and submission deadline directly in the application portal.

## Positioning choice
The original concept said AI would create new CBT techniques and overcome all psychological problems. This package intentionally reframes that claim. FearlessU personalizes clinician-reviewed, evidence-aligned CBT-informed exercises and does not claim to diagnose, cure, or replace care. New clinical techniques would require expert design and rigorous validation.

## Files
- `index.html`: full presentation site
- `styles.css`: responsive visual system
- `app.js`: menu, animations, product demo, modal
- `privacy.html`: draft privacy principles page
- `application-draft.md`: accelerator answer framework with placeholders

## Accessibility
The site includes semantic landmarks, keyboard focus states, reduced-motion support, labels, a skip link, responsive layouts, and accessible dialog behavior.
